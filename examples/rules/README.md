# Rule examples

These files are the example pairs of the twenty-five rules of the registry. The registry embeds the `Fixed` and the `Violation` file of each rule as its compliant and noncompliant example. Thus `lake exe regula`, the agent briefing and the rule-reference site show these exact bytes. Editing a file rebuilds the registry. Each file here is outside each Lake library of this repository.

No run of the checker produces these examples. The [specification of the smaller Regula](../../specification/README.md) states the cases that each rule decides.

# Code of Conduct

## Our pledge and standards

Regula adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html). Everyone participating in Regula—human contributors, reviewers, the maintainer, and anyone directing an AI agent—is expected to keep the project welcoming and harassment-free.

- Direct technical and mathematical criticism at the work (the specification, theorem, proof, check, or document), never at the person.
- Be respectful of differing viewpoints and experiences, and accept constructive criticism of claims, proofs, and designs.
- Do not engage in harassment, personal or political attacks, trolling, insulting or derogatory comments, sexualized language or imagery, or publishing others' private information without explicit permission.

## Scope

This Code of Conduct applies in all spaces managed by the Regula project on GitHub ([issues](https://github.com/rbeauchamp/regula/issues), [pull requests](https://github.com/rbeauchamp/regula/pulls), reviews, comments, and GitHub Discussions when enabled) and whenever someone represents the project in public.

## Reporting and enforcement

Regula is maintained by one owner, Richard Beauchamp ([@rbeauchamp](https://github.com/rbeauchamp)).

Report unacceptable behavior privately through [GitHub's private reporting for rbeauchamp/regula](https://github.com/rbeauchamp/regula/security/advisories/new) (Security → Advisories → Report a vulnerability, which reaches only the repository owner; see [SECURITY.md](SECURITY.md)). The owner reviews reports confidentially without promising a fixed response time and keeps the reporter's identity private.

To enforce these standards, the owner may warn a participant, edit, remove, or close comments, issues, commits, or pull requests that violate this Code of Conduct, or temporarily or permanently block an account from the repository.
